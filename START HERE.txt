==========

Why this isn't already a plain .exe
------------------------------------
I built and tested this source code, but I can't compile a Windows .exe
myself — the environment I run in is Linux with no access to Microsoft's
build servers. Handing you a "pre-built" exe would mean faking it.

What you get instead is the next best thing:

Double-click "GameWall - Click to Run.bat"
--------------------------------------------
The FIRST time you run it:
  - It checks whether you have the free .NET 8 SDK. If not, it opens the
    download page for you (one-time install, ~5 minutes).
  - It builds two real, standalone .exe files on YOUR machine.
  - It launches them and opens the remote control page in your browser.
  This first run takes a minute or two while it builds.

EVERY time after that:
  - Double-clicking the same .bat file just launches GameWall instantly.
  - Or, if you'd rather skip the .bat entirely, the real .exe files are
    sitting right here after that first build:
        dist\DisplayHost\GameWallDisplayHost.exe
        dist\ControlServer\GameWallControlServer.exe
    Double-click either one directly, same as any other Windows program.

You will need
--------------
- Windows 10 or 11
- An internet connection for the one-time first build (it downloads the
  WebView2 package) and for the one-time .NET SDK install if you don't
  already have it
- After that first build, no internet is required to run GameWall itself
  (only to load whatever streaming site you actually watch on)

Using it
--------
1. Double-click "GameWall - Click to Run.bat"
2. A window titled "GameWall Display" opens — note the IP address shown
   in its top-left corner (e.g. 192.168.1.42)
3. Your browser opens the remote page automatically on this PC
   (http://localhost:5050) — that one's ready to use immediately
4. To control it from your phone instead: connect your phone to the same
   WiFi, open a browser to http://<that-ip>:5050, and type the same IP
   into the "Display PC address" box at the top, then tap Connect
5. Tap "Test mode" to confirm your screen layout before kickoff

If something goes wrong with the first build, the .bat window will show
the actual error message — that's worth sending back for help debugging,
since I couldn't run a live build myself to catch every edge case.

Everything else (what each piece does, the streaming-network mapping
file, full command list) is in README-full-details.md.
